# SQL Projects

This repository contains my personal SQL projects and experiments, 
as well as coursework exercises from class. 

The root folder highlights my own projects, while `school-work/` contains homework exercises for reference.

---

## Personal SQL Projects

These are projects I built outside of class to practice database design, queries, and automation.

- **Inventory Management System** – Track inventory, locations, and transactions using PostgreSQL.
- **Conference Center Booking** – Manage room bookings, clients, and resources.
- **Data Analysis Scripts** – SQL scripts for analyzing datasets and generating reports.

---

## School / Coursework

These folders contain SQL exercises completed during class using **T-SQL in SQL Server Management Studio (SSMS)**. Included for completeness:

- `school-work/Queen Anne Curiosity Shop` – Homework exercises
- `school-work/Sunrise Senior Center` – Homework exercises

## Tools & Database Engines

- **T-SQL (Transact-SQL)** – SQL Server Management Studio (SSMS)
- PostgreSQL
- MySQL

## How to Use

- Each project folder contains SQL scripts and, where relevant, sample data.
- Coursework exercises were written in **T-SQL** and tested in **SSMS**.
- Personal projects may use PostgreSQL, MySQL, or SQLite.
- See individual folder READMEs for details on tables, queries, and schema.
